## `01 // PROFILE`

I build systems where **software meets hardware**.

My work focuses on combining electronics engineering, embedded systems, full-stack development, automation, and artificial intelligence into practical applications.

I enjoy working from both sides of a system:

```text

 Sensors ─┐                         ┌─ Web Applications
```
